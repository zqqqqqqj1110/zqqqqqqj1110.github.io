# 滑动窗口

## 1. [3. 无重复字符的最长子串](https://leetcode.cn/problems/longest-substring-without-repeating-characters/) 

哈希集合+滑动窗口，一旦出现重复进移动左指针

计算长度为：**有重先去重，去完重计算右-左+1**

**判断后重复移动需要用到while**

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        s = list(s)
        n = len(s)
        h = dict()
        if n == 0:
            return 0
        ans = 1
        left = 0
        for i in range(n):
            if s[i] not in h:
                h[s[i]] = 1
            else:
                h[s[i]] += 1
            while h[s[i]] > 1:
                h[s[left]] -= 1
                left += 1
            ans = max(ans, i-left+1)
            
        return ans
```

当然，哈希集合也可以用set，判断在不在可以 **i in set**

## 2.  [438. 找到字符串中所有字母异位词](https://leetcode.cn/problems/find-all-anagrams-in-a-string/) 

滑动窗口+哈希表判断

既然都小写字母直接创两个hash来判断是否相同就行，记得**循环结束再判断一下，**因为最后一个没进循环

```python
class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        p = list(p)
        s = list(s)
        ans = []
        h_p = {chr(i): 0 for i in range(97, 123)}
        h_s = {chr(i): 0 for i in range(97, 123)}
        if len(s) < len(p):
            return ans

        for i in range(len(p)):
            h_p[p[i]] += 1
            h_s[s[i]] += 1

        index = 0

        for i in range(len(p), len(s)):
            if h_p == h_s:
                ans.append(index)
            h_s[s[index]] -= 1
            h_s[s[i]] += 1
            index += 1
        
        if h_p == h_s:
            ans.append(index)
        
        return ans
```
